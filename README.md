About

This site presents my experience, projects, skills, education and contact details in one clean, responsive page. It is built as a single static page, so it loads fast and is easy to host anywhere.

Scroll animations, a scroll progress bar and a highlighted navigation link for the current section
Timeline of my degree and internship
Animated rings for CGPA and school percentages
Step-by-step flow diagrams for each project
Contact section with email, phone, LinkedIn and GitHub links
Downloadable resume (PDF)
Respects the "reduce motion" accessibility setting

Featured projects

Gold Price Prediction. Predicts gold prices from historical data using Linear Regression, Random Forest Regressor and an Artificial Neural Network. Models are compared with MAE, RMSE and R² score. Built with Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, TensorFlow/Keras and Google Colab during a 1-month AI & ML internship, in a team of two.

AgriSmart AI – Smart Agriculture Assistant. An AI-powered mobile and web app for farmers with crop recommendations, crop disease detection from leaf images (38+ plant diseases) and a farming chatbot. Built with Python, FastAPI, Node.js, React, React Native (Expo), Vite and REST APIs.
